# 固定研究目錄的假設版本一致性

## 重現與行為

同一 TTM 可比性 ASSUMPTION 的 ID／版本，原先可以在有效 hash、成功重播的兩份研究中對應不同理由、信心或 acquisition_treatment 判斷。隔離測試確認原推導結果完全相同、三項 TTM 仍 null，因此來源／紀錄／公式指紋不足以察覺假設改寫。研究也能以 canonical 假設的 ID／版本另定可比性。

共用目錄入口現在先保留 canonical ASSUMPTION 的版本指紋，再核對研究可比性假設完整定義。相同 ID／版本不同內容會拒絕；明確升版可保留舊新版，目錄正反順序皆合法。各檔案依原 request 重播，ASSUMPTION 分類、理由、信心、每項來源與判斷仍可檢視；不把分析者判斷提升為 OBSERVED。

## 實際驗證與限制

新增十項測試及相關 54 項通過，包括兩入口的理由／信心／判斷改寫、canonical 假設 ID／版本衝突、合法升版與兩份歷史的 null／分類保留、真實資料及 Fixture 隔離。全套 `npm test` 530 通過、0 失敗；兩模式 validate 都為 84 指標／25 金融公式／0 錯誤／0 警告，unknown 1／83。

沒有修改保存假設或發布新假設版本；原公式、政策、來源、觀測、研究目錄、artifact、事件、快照、金融／論點與 UI 不改。此項只核對目前載入集合的版本定義，並非完整修訂沿革、所有政策的歷史監控或一手來源認證。完整 production baseline、現在／完全稀釋股本與估值、個人投資性及原 83 個未知／三項 TTM null 均保留。
