# 工作區載入隔離與重試

選擇工作區後，金融結果必須屬於該工作區。修正前實際模擬 Production API 失敗，選單已選正式資料，仍顯示 84 張 Fixture 卡片；失敗後還重新啟用情境計算。

切換或還原基準輸入現在立即清空舊指標、情境輸入、矩陣、圖譜、論點、版本比較及已開啟的血緣視窗。載入／失敗期間沒有金融結果，計算停用；中文提示與「重新載入目前工作區」會重新取得所選工作區的基準及研究證據。成功回應須匹配模式及 Fixture flag；快速切換只接受最新請求，舊失敗也不能顯示錯誤或解鎖控制。

同工作區情境重算失敗則保留上一個成功結果，明示新輸入尚未套用；不把無效輸入顯示為計算結果。研究與手動時效原有獨立請求／日期流程保留，金融載入失敗不表示研究本身不存在。
