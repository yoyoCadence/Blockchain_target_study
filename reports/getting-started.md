# 中文開始使用

先在專案執行 `npm ci`，安裝一次依賴。Windows 可雙擊 `start-research.cmd`，其他環境執行 `npm start`，再開啟 `http://127.0.0.1:4310/`。需要 Node.js 22 以上；啟動檔的 `--check` 只檢查需求。缺少依賴時明示執行 `npm ci`，不會自行安裝；既有服務仍只監聽 loopback。終端機以 Ctrl+C 停止，沒有背景排程或自動研究。

「開始使用」提供正式證據、合成試算及手動時效三個入口。正式資料適合查看原始來源、期間及未解證據；合成資料適合學習情境重算／還原與血緣；時效須手動指定日期／查詢。各入口網址明示 `mode` 與頁內位置，切換工作區也更新網址，重新整理保留選擇；不儲存輸入或情境。空白、無效或重複模式暫停金融／研究／時效載入，選擇工作區後恢復，不默認使用 Fixture。

入門說明保留原分類、資料未知、來源日期、投資性未驗證及證據不足界線。沒有新增數字、公式、假設、論點門檻或資料品質評分；正式研究與金融模型仍分開。README 已修正「股本尚未入目錄」及「人工 refresh 尚未建立」的過時操作說明，不改歷史報告。
