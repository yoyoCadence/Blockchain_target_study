# 固定研究目錄的公式版本一致性

## 重現與行為

隔離研究把同一 `research.revenue_yoy / v1` 的 expression 或 null_policy 改寫，重新計算研究 hash 並完整重播後，原目錄與時效入口都接受。expression 測試確實產生不同 YoY 推導值。單份有效 TTM artifact 的兩份嵌入收入研究亦可保留同 ID／版本的不同公式定義，即使正式 TTM 仍因可比性未確認而為 null。

共用目錄入口現在依「公式 ID、版本」建立完整定義指紋，先保留目前 canonical 金融 registry，再加入各收入／股本研究與 TTM 本體、兩份嵌入收入研究的公式。相同 ID／版本需定義一致，包括 AST 與 null_policy；不同定義拒絕並指出公式與版本。各 reader 仍重播自己保存的公式，不以現行 spec 覆蓋舊定義。

合法新版本與舊版本可並存，目錄正反順序都合法，因為目錄不是「最新版本」時間序列。此子項不取代兩份研究的有序比較、修訂沿革或金融快照版本連續性。沒有變更任何保存公式或發布新的金融／研究公式版本。

## 實際驗證與限制

新增八項測試通過，含兩入口的 expression／null_policy 同版本改寫、單份 TTM 嵌入衝突、合法升版的正反目錄順序及真實六份研究／七份正式快照。與證據 ID／股本／時效共 44 項通過。全套 `npm test` 520 通過、0 失敗；兩模式 validate 84 指標／25 金融公式／0 錯誤／0 警告，unknown 1／83。

本次只調整共用 reader，未改研究目錄、來源、觀測、artifact、事件、快照、政策、假設、公式定義或 UI。原始數值、金融／論點、全部歷史及三項正式 TTM null 保留；未新增瀏覽器 QA。此防線核對載入集合中的公式版本定義，不重新認證一手來源或建立現在股本／估值。完整父 baseline 仍未完成。
