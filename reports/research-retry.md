# 研究證據單獨重試

入門的正式證據入口需要在研究 API 單獨失敗後可恢復。實際模擬研究 503：金融 84 指標仍成功載入，研究清單為空且只有錯誤文字，原先沒有獨立重試；完整工作區重載會清空尚未套用的試算輸入。

現在失敗時顯示「重新載入研究證據」，只重新讀取所選模式的研究目錄，不重載金融或時效、不清空情境輸入。載入時清空舊研究、標示 busy、隱藏重試；成功回應須匹配模式。失敗仍可再試，只有最新請求能修改狀態或解鎖；舊成功／失敗不覆蓋最新工作區。這是手動唯讀恢復，不自動重試、採集或補值。
